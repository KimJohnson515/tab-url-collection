# 탭 정리기 (Tab Organizer)

열려 있는 크롬 탭을 **열람 횟수 · 체류 시간 · 최근 접근**으로 점수를 매겨 우선순위별로 나누고,
문서 / 스프레드시트 / 이메일로 한 번에 내보내는 확장 프로그램입니다.

## 설치 (개인용)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더(`tab-organizer`) 선택
4. 툴바의 퍼즐 아이콘에서 "탭 정리기"를 고정하면 편합니다

크롬 121 이상이 필요합니다. (탭의 `lastAccessed` 값을 사용)

## 사용법

툴바 아이콘을 누르면 열린 탭이 **높음 / 보통 / 정리 후보** 세 단계로 나뉘어 보입니다.

- 체크박스로 내보낼 탭을 고릅니다. (단계 제목의 체크박스는 그 단계 전체)
- 탭 제목을 누르면 그 탭으로 이동합니다.
- **문서**: Markdown 저장 · HTML 저장(표 형태, 인쇄 가능) · Markdown 복사
- **시트**: CSV 저장(엑셀에서 한글 정상 표시) · 구글 시트로 복사(표를 복사하고 새 시트를 엽니다 → A1 셀에 붙여넣기)
- **즐겨찾기**: 기타 즐겨찾기 안에 `탭 정리 2026-10-15 07:52` 같은 폴더를 새로 만들고, 우선순위 순서대로 `1. 제목`, `2. 제목` … 으로 저장합니다.
  (10개 이상이면 `01.`, `02.`처럼 자릿수를 맞춥니다. 같은 주소는 가장 높은 순위 하나만 저장하며, 실행할 때마다 새 폴더가 만들어집니다.)
- **메일**: Gmail 작성 창 또는 기본 메일 앱으로 열기. 받는 사람은 비워 둬도 됩니다.
  메일 본문은 길이 한도가 있어 점수가 낮은 탭부터 생략되며, 전체 목록은 클립보드에 복사됩니다.

## 점수 계산 (lib.js 맨 위 `CONFIG`에서 조정)

| 항목 | 점수 |
| --- | --- |
| 열람 횟수 | 1회당 3점, 최대 10회(30점) |
| 체류 시간 | 30분 이상이면 40점, 그 아래는 비례 |
| 최근 접근 | 방금 본 탭 30점, 6시간마다 절반 |
| 가산점 | 고정 탭 +15, 소리 재생 중 +10, 지금 보는 탭 +10 |

기준: 35점 이상 **높음**, 12점 이상 **보통**, 그 미만 **정리 후보**

## 기록 방식과 한계

- **열람 1회 = 그 탭에 5초 이상 머문 방문**입니다. Ctrl+Tab으로 탭을 훑어보거나 잠깐 스쳐 지나간 것은 세지 않습니다.
- 열람 횟수와 체류 시간은 **설치한 뒤부터** 이 확장 프로그램이 직접 기록합니다. 탭을 닫으면 그 탭의 기록도 삭제됩니다.
- 숫자가 이상하면 팝업 아래쪽의 **기록 초기화**로 처음부터 다시 쌓을 수 있습니다.
- 설치 전부터 열려 있던 탭은 "기록 없음"으로 표시되고, 최근 접근 시각만으로 점수를 매깁니다.
- 체류 시간은 창이 포커스되어 있고 60초 이상 입력이 멈추지 않았을 때만 쌓입니다. 정확한 측정값이 아닌 근사치입니다.
- 브라우저를 다시 시작하면 탭 ID가 바뀌므로 기록이 초기화됩니다.
- 시크릿 창의 탭은 "시크릿 모드에서 허용"을 켠 경우에만 보입니다.

## 개인정보

모든 기록은 내 컴퓨터의 `chrome.storage.local`에만 저장되고 외부 서버로 전송되지 않습니다.
탭 목록은 사용자가 버튼을 눌렀을 때만 파일·클립보드·메일 작성 창·즐겨찾기로 나갑니다.
`bookmarks` 권한은 "즐겨찾기 폴더로 저장"에서 새 폴더를 만들 때만 사용하며, 기존 즐겨찾기를 읽거나 수정·삭제하지 않습니다.
스프레드시트가 수식으로 해석하지 않도록 `=`, `+`, `-`, `@`로 시작하는 제목에는 앞에 `'`가 붙습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | 확장 프로그램 설정 (MV3, 권한: tabs · storage · idle · alarms · clipboardWrite · bookmarks) |
| `background.js` | 열람 횟수·체류 시간 기록 (서비스 워커) |
| `lib.js` | 점수 계산, Markdown/HTML/CSV/이메일 생성 |
| `popup.html` `popup.css` `popup.js` | 팝업 화면 |
